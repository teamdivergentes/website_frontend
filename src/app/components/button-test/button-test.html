Story 1.3 - Button Components Test

Page de test des 3 variants de boutons: btn-cta, btn-badge, btn-ghost avec tous les states (hover, focus, disabled).

btn-cta (Call-to-Action)

Bouton primaire avec fond vert. Hover: scale-105 | Focus: ring vert 2px | Disabled: opacity 50%

btn-badge (Secondary)

Bouton secondaire avec bordure verte. Hover: remplissage vert | Focus: ring vert 2px | Disabled: opacity 50%

btn-ghost (Tertiary)

Bouton tertiaire minimal. Hover: fond gris subtil | Focus: ring vert 2px | Disabled: opacity 50%

Test Accessibilité (NFR-A11Y-3)

Utilisez Tab pour naviguer entre les boutons. Le focus doit être visible avec un ring vert de 2px.

Note: Les boutons disabled sont automatiquement exclus du tab order.

Test Transitions (200ms)

Les transitions doivent être fluides (200ms, ease). Pas de lag ou saccade visible.
