Google Analytics non configuré

Le dashboard Analytics nécessite une connexion à Google Analytics Data API.
Aucune propriété GA4 n'est configurée sur ce serveur.

Comment configurer

  1. Créez une propriété Google Analytics 4 sur analytics.google.com
  2. Activez l'API Google Analytics Data dans Google Cloud Console
  3. Créez un compte de service et téléchargez le fichier JSON de credentials
  4. Ajoutez le compte de service en tant que lecteur sur votre propriété GA4
  5. Configurez les variables d'environnement backend : GA_PROPERTY_ID et GOOGLE_APPLICATION_CREDENTIALS
  6. Redémarrez le serveur backend
